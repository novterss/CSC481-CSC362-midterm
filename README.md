An interactive single-page study hub for two back-to-back midterm exams at Rangsit University.

## ✨ Content / เนื้อหา

**CSC362 Database Systems**
- Normalization masterclass: UNF → 1NF → 2NF → 3NF
- ER diagram design (Chen and Crow's Foot notation)
- Mapping an ER diagram to a relational schema
- Keys and relational integrity
- Practice quiz with instant checking and explanations

**CSC481 System Analysis and Design**
- SDLC (5 phases), Waterfall vs. Agile, fact-finding techniques
- Feasibility (5 aspects), SWOT and TOWS matrix
- Critical Path Method (CPM) with an interactive network diagram, and Gantt charts
- Data Flow Diagrams (DFD) and their 3 key rules
- Fishbone (Ishikawa) diagram with real exam-style problems
- 15-question "Review the Lesson" quiz

**Extras**
- Exam-day rules and a plan for handling two exams in a row
- A 5-minute "Master Blueprint" cheat sheet for last-minute review

## 🛠️ Tech Stack

Plain HTML, CSS and JavaScript with no build step and no dependencies. Diagrams are drawn with inline SVG.
